[Ploggo 알고리즘 테스트 — 서비스 반영 검토 항목]
근거: avoidZoneTest v3(260727) / v4(260729) / v4(260731) 실험 결과

────────────────────────────────────────────────
■ 배경: 세 번의 실험에서 확인된 사실
────────────────────────────────────────────────
- 회피구역(공업지대) 통과 경로 중 68~71%는 알고리즘으로 해소되지 않는다.
  표본 조건을 세 가지로 바꿔가며 검증했으나 수치가 일정하다.
  → 원인은 알고리즘이 아니라 인천 공업지대의 도로 구조 자체다.
    (핫스팟 후보 평균 19.4개 중 회피구역 소속은 1.94개에 불과.
     지점 선택은 정상 작동하나, 지점을 잇는 도로가 공단을 관통함)
- 반면 해결 가능한 케이스에서는 성과가 뚜렷하다.
  교차 발생 165건 중 완전 제거 37건(22%), 50% 이상 감소 53건.
- 부작용 없음: 회피구역과 무관한 경로 50건에서 swap 0.02회, 거리 증가 0.04km.

────────────────────────────────────────────────
■ 검토 항목 1: 사전 예측 안내 (스낵바 등)
────────────────────────────────────────────────
[근거 데이터] OD 직선이 회피구역을 가로지르는 길이 = 실패 예측 지표

  직선 통과 길이    OD 수    회피 실패(hard case) 비율
  500m 미만          27               33%
  500m ~ 1km         52               56%
  1km ~ 2km          72               74%
  2km 초과           41               95%

  ※ v4 두 차례 실험에서 동일 패턴 재현 → 지표 안정성 확인

[구현 특성]
- 출발지·도착지 좌표만으로 계산 가능. Tmap API 호출 불필요.
- 경로 계산 전에 즉시 판정되므로 지연 없음. 추가 비용 없음.
- 계산 방식: OD 직선과 회피구역 폴리곤의 교집합 길이

[안내 시점 후보]
- 2km 초과(실패율 95%): 경로 계산 전 사전 고지
- 1~2km(실패율 74%): 경고 수준 안내
- 1km 미만: 안내 불필요

[논의 필요 사항]
- 안내 형식(스낵바/모달/인라인 텍스트)
- 임계값을 2km로 할지 1km로 할지
- 안내 후 사용자 행동 옵션(그대로 진행 / 출발지 변경 / 취소)

────────────────────────────────────────────────
■ 검토 항목 2: 출발지 조정 제안
────────────────────────────────────────────────
[근거 데이터] O·D와 회피구역 경계 간 이격 거리별 성능 (각 구간 63~66개 OD)

  이격 거리    회피 실패 비율    총 교차 감소율    완전 제거 건수
   100m           77.8%            12.5%              1건
   300m           77.8%            26.6%              9건
   500m           48.5%            38.0%             27건

[해석]
- 500m를 기점으로 성능이 크게 개선된다(실패율 78% → 49%).
- 원인: 500m 구간은 공단 통과 직선 길이가 706m로 다른 구간(약 1,250m)의 절반.
  즉 공단을 얕게 스치므로 우회 여지가 존재한다.
- 대가: 도보 거리가 평균 0.45km 증가(100·300m 구간은 0.04~0.05km).
  → 우회로가 없어 그냥 통과하는 것과, 돌아가서 피하는 것의 차이.

[논의 필요 사항]
- 제안 트리거: 출발지가 회피구역 500m 이내일 때
- 제안 방식(대안 출발지 지도 표시 / 텍스트 안내)
- 도보 거리 0.45km 증가를 사용자에게 어떻게 고지할지
- 플로깅 특성상 거리 증가가 오히려 긍정적일 수 있음(활동량 증가) → UX 문구 검토

■ 검토 항목 3: 알림 임계값 (ALGO_HARD_CASE_M)
────────────────────────────────────────────────
[현재 권장값] 691m
  산출 근거: 회피 실패 케이스 130건의 잔존 교차 거리 25퍼센타일(692m)
  의미: 경로가 회피구역을 691m 이상 지날 때만 사용자에게 알림 표시
  체감 수준: 도보 약 8~9분

[값 변경 시 영향]
- 낮추면 알림 빈도 증가(과다 알림으로 사용자가 무시할 위험)
- 높이면 알림 빈도 감소(알려야 할 경우를 놓칠 위험)

[참고 분포] 잔존 교차 거리
  25퍼센타일 692m / 중앙값 1,793m

[논의 필요 사항]
- 알림 문구(거리 표시 여부, 표현 수위)
- 베타 운영 중 실제 알림 발생률 모니터링 후 조정 전제
- 이 값은 경로 계산에 관여하지 않음. 알림 표시 여부만 결정함.
